Comet 0.1.0, portable

Run Comet. Nothing is installed and nothing is written next to
it: your library and settings live in %APPDATA%\Comet, and removing
this folder removes the program.

Windows 10 and 11 already have the WebView2 runtime that Comet draws
its interface with. On an older or stripped-down Windows, install it
once from https://developer.microsoft.com/microsoft-edge/webview2/
